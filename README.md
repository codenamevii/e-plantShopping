# e-plantShopping — Paradise Nursery

**Paradise Nursery** (`e-plantShopping`) is a front-end React and Redux Toolkit web application for browsing and shopping for houseplants.

## Overview

- **Landing Page:** Introduces **Paradise Nursery** with a background image, company overview, and a **Get Started** button to enter the store.
- **Product Listing Page:** Displays houseplants organized into categories with thumbnail images, plant names, prices, and **Add to Cart** buttons that disable once added.
- **Navigation Header:** Appears across product and cart views with navigation links and a live cart counter reflecting total items in the cart.
- **Shopping Cart Page:** Shows total plant count, total cart cost, per-plant subtotals, quantity increase/decrease controls, item removal, a **Continue Shopping** button, and a **Checkout** button.
